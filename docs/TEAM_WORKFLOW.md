# Individual project workflow

The current contributor owns implementation, integration, tests, and documentation.
Use focused feature branches from `dev`, review the complete diff, and open a PR
into `dev`. Merge `dev` into `main` only after the exact submitted commit has a
successful `CI required` check. Configure both branches to require that check;
retain existing review rules until an authorized administrator/instructor changes them.

For Unit 5, record an actual independent review or written instructor approval
for the solo alternative. A checklist or AI-assisted report does not establish
peer review. Keep commits focused, explain approved API changes, and submit the
commit SHA, CI run URL, local integration evidence, and known-debt register.
