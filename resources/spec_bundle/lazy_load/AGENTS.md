# Lazy-load package-generation router

Use this domain when the user asks to create, rebuild, expand, or update the repository's lazy-loaded `AGENTS.md` package.

| Intent | Read |
| --- | --- |
| Rebuild/update complete SkillMatch AGENTS overlay/package | `build_package.md` |
| Understand required router/leaf/spec architecture | `package_contract.md` |
| Inspect required package/story catalog | `package_manifest.md` |
| Create/revise TDD user stories from project specs | `story_generation_contract.md` |
| Validate a generated package | `validation_contract.md` |
| Review the user's generic lazy-load instructions | `source_instructions.md` |

Do not read every file here by default. `build_package.md` names the extra context for a complete rebuild.
