# Unit 8 Assignment 1 - Final Project Portfolio acceptance

Do not execute this phase automatically after Alpha.

## Team repository

Fully working integrated application; functional AI feature; CI/CD documentation/evidence; README, API docs, installation guide, user manual; code-review evidence, coverage reports, performance benchmarks; professional repository organization/naming/version control; names/contributions.

## Stakeholder presentation

10-15 minutes covering problem, solution/architecture, live AI demonstration/value, implementation/integration, reliability/scalability/performance metrics, stakeholder value.

## Individual 1,300-word paper

- 400 words: system delivery/integration.
- 450 words: methodology/performance evaluation with quantitative evidence and SEI/IEEE/equivalent sources.
- 450 words: professional development roadmap with current authoritative trend sources.

Never invent CI runs, deployment screenshots, review records, benchmark numbers, coverage, commits, or external-source conclusions.
